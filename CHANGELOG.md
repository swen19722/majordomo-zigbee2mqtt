# История изменений

## 1.0.0

- Обработка retained-сообщения `bridge/devices` при подключении и обновлении списка. Сохранена обработка списка старого формата.
- Автоматическое заполнение карточки по метаданным Zigbee2MQTT. Для устройств с известным изображением используется существующий каталог.
- Привязка записей устройств к IEEE-адресу и перенос путей MQTT при переименовании.
- Поддержка JSON и текстового статуса шлюза. Убрана принудительная маркировка координатора как CC2531.
- Добавлены инструкции установки, обновления и отката.
