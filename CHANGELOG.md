# История изменений

## 1.0.1

- Карточки показывают модель, производителя, бренд и описание из Zigbee2MQTT. Для изображения используется модель, а при недоступном фото отображается иконка типа устройства.
- Показания берутся из последних данных устройства. Список и единицы измерения определяются по `definition.exposes`.
- Индикатор шлюза читает `bridge/state`. Режим сопряжения отображается по `bridge/info` и переключается через современный MQTT API с поддержкой старых шлюзов.
- В панели управления отображается версия модуля.

## 1.0.0

- Обработка retained-сообщения `bridge/devices` при подключении и обновлении списка. Сохранена обработка списка старого формата.
- Автоматическое заполнение карточки по метаданным Zigbee2MQTT. Для устройств с известным изображением используется существующий каталог.
- Привязка записей устройств к IEEE-адресу и перенос путей MQTT при переименовании.
- Поддержка JSON и текстового статуса шлюза. Убрана принудительная маркировка координатора как CC2531.
- Добавлены инструкции установки, обновления и отката.
